# 工作小结写作小助手 (Work Summary Assistant)

## 📖 简介

这是一个智能的工作小结写作助手skill,能够通过交互式对话引导用户逐步提供必要信息,然后自动生成一份结构清晰、内容充实的工作小结文档。

## 🎯 功能特点

- **智能触发**: 当用户提到"工作小结"、"工作总结"、"月度总结"、"季度总结"、"年度总结"等关键词时自动触发
- **交互式引导**: 使用`ask_followup_question`工具逐步引导用户,一次只问一个问题
- **灵活收集**: 根据用户回答动态调整问题,尊重用户意愿
- **智能省略**: 如果用户表示某项信息"没有",自动在最终文档中省略该部分
- **结构化输出**: 生成包含多个章节的专业工作小结文档

## 🚀 使用方法

### 触发方式

只需说以下任何一种话即可触发skill:

```
帮我写一份工作小结
写个工作总结
我是产品经理,帮我写个月度总结
需要写个年度总结
帮我写份季度总结
```

### 交互流程

1. **第一步**: 选择总结类型(月度/季度/年度)
2. **第二步**: 提供基本信息
   - 岗位信息
   - 主要工作内容
   - 突出成绩
   - 工作不足
   - 获奖情况
3. **第三步**: 补充信息(可选)
   - 团队协作情况
   - 技能提升
   - 下阶段计划
   - 遇到的挑战
   - 创新改进
4. **第四步**: 生成完整的工作小结文档

## 📄 输出示例

生成的工作小结包含以下结构(根据实际信息动态调整):

```
# [时间周期]工作小结

## 一、岗位信息
[岗位名称]

## 二、主要工作内容
[详细描述主要工作职责和任务]

## 三、工作成果与亮点
[突出成绩和重要成果]

## 四、获奖情况
[列出获得的奖项和荣誉]

## 五、工作中的不足
[分析不足之处和需要改进的地方]

## 六、遇到的挑战与解决方案
[描述主要挑战及应对措施]

## 七、技能提升
[描述学习的新技能或能力提升]

## 八、团队协作
[描述团队协作情况和贡献]

## 九、下阶段工作计划
[规划下一阶段的工作目标和重点]

## 十、总结与展望
[整体总结和对未来的展望]
```

## 🎨 写作特点

- **语言风格**: 正式、专业,但不过于生硬
- **内容充实**: 基于用户提供的信息进行适当扩展
- **逻辑清晰**: 各部分之间有良好的逻辑关联
- **实事求是**: 不夸大成绩,不回避问题
- **重点突出**: 突出主要成绩和重要工作
- **数据支撑**: 如果用户提供具体数据,会在总结中体现

## 💡 使用技巧

1. **提供详细信息**: 在初始提示中可以直接提供部分信息,如"我是产品经理,帮我写个月度总结"
2. **数据量化**: 尽量提供具体的数据,如完成率、增长率、项目数量等
3. **如实回答**: 对于可选信息,如果没有可以直接说"没有",skill会自动省略该部分
4. **后续调整**: 生成文档后,可以要求skill进行修改或调整

## 🔧 技术实现

- **工具**: 使用`ask_followup_question`进行交互式问答
- **流程**: 4步工作流程,逐步收集信息
- **输出**: Markdown格式的结构化文档
- **语言**: 中文
