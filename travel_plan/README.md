# Travel Plan 技能

## 技能简介

`travel_plan` 是一个专业的旅游计划书生成技能,能够根据用户提供的旅游信息,自动生成详细、实用的旅游计划书。

## 核心功能

1. **智能信息收集**: 当用户提供的信息不完整时,会主动询问并引导用户补充必要信息
2. **详细行程规划**: 根据目的地和天数,合理安排每日行程
3. **景点深度介绍**: 提供每个景点的详细介绍、游览时长、门票信息
4. **交通路线规划**: 包含去程、返程和当地交通的详细方案
5. **天气信息查询**: 提供出行期间每日的天气情况和穿衣建议
6. **费用预算估算**: 给出交通、住宿、门票、餐饮等费用预算

## 使用场景

- 用户说"我想计划一次旅游"、"帮我规划旅行"
- 用户提到具体的旅游目的地和行程安排需求
- 用户需要详细的旅游行程建议
- 用户询问某个地方怎么玩、玩几天合适

## 必需信息

技能会确保收集以下关键信息:
- 旅游目的地
- 旅游天数
- 出行方式
- 出发地点
- 出行日期

## 输出内容

生成的旅游计划书包含:

### 1. 基本信息
- 目的地、天数、日期、出行方式、出发地

### 2. 每日行程安排
- 每天的详细行程时间表
- 景点介绍和游览建议
- 餐饮推荐
- 住宿建议
- 当日天气情况

### 3. 交通总览
- 去程和返程交通方案
- 当地交通建议
- 交通费用预估

### 4. 费用预算
- 各项费用的详细分解
- 总预算金额

### 5. 注意事项
- 天气相关提醒
- 交通注意事项
- 景点游览建议

### 6. 必备物品清单
- 根据天气和行程推荐携带的物品

## 技能特点

1. **用户友好**: 逐步收集信息,不会让用户感到负担
2. **内容丰富**: 提供实用的景点介绍和交通信息
3. **结构清晰**: 输出格式化的 PDF 文档,易于阅读和分享
4. **个性化**: 根据用户的出行方式和偏好调整建议
5. **实用性强**: 所有建议都具体可行,包含实际可用的信息
6. **PDF 输出**: 生成专业的 PDF 格式旅游计划书,方便打印和保存

## 使用示例

**示例 1: 信息完整的情况**
```
用户: 我想计划一次去北京的旅游,玩5天,从上海出发,坐高铁,4月20日出发

技能: 直接开始规划,生成完整的北京5日游计划书
```

**示例 2: 信息不完整的情况**
```
用户: 帮我规划一下去成都的旅行

技能: 询问天数、出发地、出行方式、出发日期等信息
```

**示例 3: 自驾游**
```
用户: 我想去三亚度假,3天2晚,从广州自驾过去,5月1日出发

技能: 生成包含自驾路线、停车场信息的三亚旅游计划
```

## 注意事项

- 技能会使用 TodoWrite 工具跟踪规划进度
- 会使用 ask_followup_question 工具收集缺失信息
- 最终会生成 PDF 格式的旅游计划书文件
- 文件命名格式: `[目的地]旅游计划_[日期].pdf`
- PDF 生成需要安装相关依赖(markdown-pdf、weasyprint 或 pandoc)

## PDF 生成依赖

**自动安装**: 技能会自动检测并安装所需的 PDF 转换工具,无需用户手动操作。

技能支持多种 PDF 转换方式,按优先级自动尝试:

**方式 1: markdown-pdf (推荐,自动安装)**
```bash
pip install markdown-pdf
```

**方式 2: markdown + weasyprint (自动安装)**
```bash
pip install markdown weasyprint
```

**方式 3: pandoc (需手动安装)**
- Windows: 从 https://pandoc.org/installing.html 下载安装
- macOS: `brew install pandoc`
- Linux: `sudo apt-get install pandoc`

**自动安装流程**:
1. 检查 markdown-pdf 是否已安装
2. 如未安装,自动执行 `pip install markdown-pdf`
3. 如果安装失败,尝试安装 markdown + weasyprint
4. 如果都失败,提示用户手动安装,并保留 Markdown 文件作为备选
